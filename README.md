# DocuSign CLM Airtable Extension — Landing Page & Marketing Site

A lightweight, high-converting marketing landing page designed to promote and sell the **DocuSign CLM Airtable Extension**. Built with static HTML, Tailwind CSS, and Feather Icons, this repository is optimized for instant hosting via **GitHub Pages** with zero build tools or complex deployment pipelines required.

---

## Live Demo & Website Preview

- **Live URL**: `https://bhkbdbhatt.github.io/airtable-docusign-clm-sync-site/`
- **Hosted On**: GitHub Pages
- **Tech Stack**: HTML5, Tailwind CSS (via CDN), Feather Icons, Pure CSS

---

## Features

- **High-Converting Hero Section**: Highlights key value propositions with primary CTAs, trust badges, and an interactive UI wireframe preview.
- **Interactive UI Mockup**: Visual representation showing how the Airtable Extension triggers workflows and fetches PDF documents.
- **Features Grid**: Highlights Dynamic Field Mapping, OAuth2 JWT Authentication, and In-App PDF Viewing.
- **Pricing Matrix**: Built-in conversion cards for Single Base ($49/mo) and Enterprise ($149/mo) plans with direct payment link integration (Stripe / Lemon Squeezy).
- **Responsive & Dark-Themed**: Modern, dark-mode aesthetic with custom scrollbars and smooth scrolling navigation.
- **Zero Build Step**: No `npm install` or bundlers needed—edit `index.html` and push directly to GitHub.
